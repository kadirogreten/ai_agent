# Hibe yazımı — sözlük (ilk terim kümesi)

| Terim | Açıklama |
| --------- | --------- |
| İş paketi (WP) | Amaç, süre ve teslimlerle tanımlı alt çalışma paketi |
| Yenilik iddiası | Mevcut yönteme göre somut iyileştirme / yeni çözüm iddiası |
| Bilinen durum (state of the art) | Literature ve uygulamada kabul görü çıkış noktası |
| TRL | Technology Readiness Level (1–9) |
| Eligible cost (uygun maliyet) | Çağrıda kabul gören gider türleri |
| Dissemination | Sonuçların yayılması (etkinlik, yayın, açıklama) |
| Exploitation | Ticari veya operasyonel değere dönüştürme planı |
| Konsorsiyum | Ortaklar, roller ve sorumluluklar |
| Kilometre taşı | Döneme bağlı doğrulanabilir ara teslim kontrolü |
| Çağrı metni | Resmi program başvuru koşulları (birincil kaynak) |
