# E-ticaret sözlüğü — P0 terimler (Türkçe / EN)

Bu dosya playbook ve verifier çıktılarında ortak dil için referanstır. Terimleri çevirirken bu tabloyu kullanın.

| Terim | Kısaltma | Türkçe / açıklama |
| ----- | -------- | ----------------- |
| AOV | Average Order Value | Ortalama sepet tutarı |
| ATC | Add to Cart | Sepete ekle |
| PDP | Product Detail Page | Ürün detay sayfası |
| PLP | Product Listing Page | Liste / kategori sayfası |
| CVR | Conversion Rate | Dönüşüm oranı (ör. ziyaret → satış) |
| CTR | Click-Through Rate | Tıklanma oranı |
| SKU | Stock Keeping Unit | Stok kodu |
| GMV | Gross Merchandise Value | Brüt işlem hacmi |
| PDP SEO | — | Ürün sayfası arama uyumu |
| PDP content | — | Açıklama, görseller, teknik özellikler |
| Checkout | — | Ödeme adımları (sepet → ödeme → onay) |
| PDP trust | — | Güven işaretleri, iade, iletişim |
| SLA | Service Level Agreement | Hizmet seviye taahhüdü (kargo, destek süresi) |
| PDP / PLP CLS LCP INP | Web Vitals | Sayfa kalite göstergeleri (özeti değerlendirmede) |
| COD | Cash on Delivery | Kapıda ödeme |

**Not:** Sayısal iddialar (satış payı, büyüme oranı vb.) için her zaman güvenilir URL kanıtı istenir (`rubrics/verifier.md`).
